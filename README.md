# تطبيق إدارة الديون - Flutter

هذه نسخة أولية بواجهة عربية RTL تتضمن:
- لوحة إجماليات الدين والمسدد والمتبقي.
- إضافة أشخاص مع الاسم والهاتف ومبلغ الدين والملاحظات.
- تفاصيل الشخص وسجل التسديدات.
- البحث بالاسم أو رقم الهاتف.
- صفحة إحصائيات.

## التشغيل
1. ثبّت Flutter وAndroid Studio على الكمبيوتر.
2. أنشئ مشروعاً جديداً: `flutter create flutter_debt_manager`
3. استبدل محتوى `lib/main.dart` بهذا الملف.
4. استبدل `pubspec.yaml` بالملف المرفق.
5. نفّذ:
   `flutter pub get`
   ثم `flutter run`

## ملاحظة مهمة
هذه النسخة تحفظ البيانات في الذاكرة فقط؛ ستختفي البيانات عند إغلاق التطبيق بالكامل. قبل الاستخدام الحقيقي، ينبغي إضافة قاعدة بيانات محلية (مثل SQLite/Drift) ونسخ احتياطي، ثم ميزات PDF والإشعارات وقفل التطبيق.
